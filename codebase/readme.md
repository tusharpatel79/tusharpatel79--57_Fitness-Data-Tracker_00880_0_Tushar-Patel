##Fitness Data Tracker

## Project Overview
The **Fitness Data Tracker** is a comprehensive application designed to help users monitor and manage their daily physical activities. By logging various workouts, the system calculates key health metrics such as calories burned and active duration, empowering users to stay on top of their personal fitness goals.

## Key Features
- **Activity Logging:** Easily record different types of exercises, including cardio, strength training, and flexibility routines.
- **Calorie Calculation:** Automatically estimates calories burned based on the type of activity, duration, and user metrics.
- **Progress Monitoring:** Provides a clear summary of daily and weekly fitness achievements.
- **Data Persistence:** Saves user data locally to track long-term fitness trends.

## Technologies Used
- **Language:** Python
- **Libraries:** Standard Python Libraries (math, datetime)
